Requirement 1: Aviator page: https://www.opentext.com/aviator-ai
1. As a website visitor, when I navigate to the OpenText Aviator page in the test
environment, I should see the page load successfully with the correct title “AI for
Business &amp; Enterprise AI Platform | OpenText”.
2. Hero/primary page load should display all key elements of the OpenText Aviator
page without errors.
3. As a user, I should see a Secondary Navigation along with the main header
containing:
o Products, Solutions, Support &amp; Services, Partners, Resources
o Secondary nav items: Aviator icon, Aviator AI, Get Started, Play, Explore,
Learn (dropdown)

4. When I interact with the Secondary Navigation, all links should open correctly
without errors.
5. When I scroll down the page, the main header should hide and only the
Secondary Navigation should remain visible.
6. When I scroll up, the main header should reappear.
7. No console errors should be observed during navigation or scrolling.
8. As a user, I should see a section titled “OpenText Aviator” with description.
9. The section should display a 3-column Bento Grid:
o 1 featured card (center)
o 4 regular cards (side columns)
10. When I hover (or tap on mobile) on regular cards, they should flip and display
content on the backside.
11. The featured card should display:
 Background (pattern/image)
 Eyebrow, heading, description, CTA buttons
12. When I click on any of the 4 regular cards, the respective pages should open
correctly.
13. When I click on CTA buttons, they should navigate correctly.

Scenario Library Component
14. As a user, I should see a Scenario Library component with:
 Eyebrow, Title, optional description
 Horizontal tabs
15. The first tab should be selected by default.
16. When I switch tabs, the respective content should be displayed.
17. Each tab should include:
 Header (eyebrow, title, description, tags)
 Accordion list (expandable/collapsible)
 Optional carousel, CTA buttons, and side card
18. All tabs, accordions, and interactive elements should function correctly without
errors.
